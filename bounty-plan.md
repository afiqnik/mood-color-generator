# Bounty Engineering Plan

**Project:** Mood → Color Generator  
**Developer:** Nik Afiq  
**Stack:** HTML, CSS, Vanilla JavaScript  
**Scope:** Static frontend only

## Problem and Goal

Help users find a simple five-color palette that visually represents a selected mood.

## Target Users

Anyone looking for quick color inspiration.

## MVP Requirements

- [✅] Mood selection
- [✅] Generate the corresponding five-color palette.
- [✅] Reset to the initial state.
- [✅] Include “Powered by Codyza”.

## Technical Decisions

- Store palette data in JavaScript.
- Use semantic HTML and responsive CSS.
- No backend, database, authentication, or external API.

## Delivery Checklist

- [✅] GitHub repository updated.
- [✅] Codyza branding is visible.
