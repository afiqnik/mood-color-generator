# Mood → Color Generator

A small, responsive web app that matches a selected mood with a predefined five-color palette. Built with HTML, CSS, and vanilla JavaScript for a Codyza bounty.

## Features

- Choose from eight moods: Happy, Calm, Energetic, Romantic, Sad, Nature, Focused, and Cozy.
- Generate a five-color palette for the selected mood.
- View and copy individual HEX values.
- Reset the interface and choose another mood.
- Responsive layout for desktop and mobile.

## Tech Stack

- HTML
- CSS
- Vanilla JavaScript
- No backend, database, authentication, or external API.

## Getting Started

1. Clone or download this repository.
2. Open `index.html` in a modern browser.

No package installation or build step is required.

Palettes are predefined. The app does not save palettes or use AI to create new ones.
